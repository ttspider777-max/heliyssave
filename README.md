# SaveMod bot (Telegram Business)

## Запуск
```
pip install -r requirements.txt
python main.py
```
Токен и ID главного админа лежат в `.env`.

## Обязательно в @BotFather
`/mybots` → бот → **Bot Settings → Business Mode → Turn on**. Без этого бота нельзя подключить через Telegram для бизнеса.

## Подключение (для пользователя, нужен Telegram Premium)
Настройки → Telegram для бизнеса → Чат-боты → выбрать бота → доступ ко всем личным чатам →
включить права «Ответ на сообщения» и «Удаление сообщений».

## Функции
- Уведомление об удалённых сообщениях собеседника (текст и любые медиа) и об изменённых.
- `.mute` / `.unmute` в чате: сообщения замьюченного сразу удаляются.
- `.save` ответом: копия сообщения в бота. `.busy текст` / `.free`: быстрый автоответ.
- `.mogged`: чисто визуальная анимация «сноса» аккаунта собеседника (одно сообщение редактируется по кадрам
  и заканчивается карточкой «Удалённый аккаунт»). Нужно право «Ответ на сообщения».
- Автоответ: режимы «Занят» (всегда) и «Не в сети» (владелец не писал N минут), с кулдауном на чат.
- Антискам: по словам-триггерам удаляет сообщение и мьютит отправителя, владельцу приходит кнопка «Разблокировать».
  Настоящую блокировку Bot API сделать не даёт, поэтому «блок» = вечный мут с автоудалением.
- Админка `/admin`: статистика, топ запусков, новые юзеры, инфо по ID, бан/разбан (также `/ban ID причина`, `/unban ID`),
  список банов, рассылка, редактирование антискам-слов, экспорт CSV, очистка кэша, управление админами.

Удалённые сообщения показываются, только если бот видел их при отправке (т.е. после подключения).
